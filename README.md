# Student Task Manager

A simple website to manage student tasks and assignments using HTML, CSS, and JavaScript.

## Features
- Add study tasks and assignments
- Set due dates
- Mark tasks as completed
- Delete tasks
- Filter pending and completed tasks
- Save tasks in the browser

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download the project files.
2. Open `index.html` in your web browser.
3. Start managing your tasks.

## Purpose
This project was created to practice web development and learn how to upload projects to GitHub.
